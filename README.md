# Корпоративная программа жилищного обеспечения ПАО «Газпром»

Одностраничный адаптивный сайт-буклет с ипотечным калькулятором.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```text
node server.cjs
```

После этого сайт будет доступен по адресу `http://localhost:8080`.

## Структура

- `index.html` — текст и семантическая структура буклета;
- `styles.css` — фирменная адаптивная стилистика;
- `app.js` — навигация, калькулятор, графики и экспорт графика платежей в CSV;
- `assets/` — локальные графические материалы.

Все расчёты выполняются локально в браузере.
